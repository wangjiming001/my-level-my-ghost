# v12 跑速候选实验（未推广）

独立复制 v11 基线，模拟跑速86单位/tick、追赶速度129、移坑速度109；生产 `src/engine.js` 保持v11。原作跑速仅为录像估算，原作碰撞盒未知。运行 `node experiments/speed-v12/validate.cjs` 重现五关、平移布局、延迟反应、回放和快照检查。

`node experiments/speed-v12/test/falling_block_route_test.js` 当前预期失败：v11 固定的上台跳跃路线在v12更快的水平速度下提前触发落石，在落稳之前被击中。`node experiments/speed-v12/block-detail.cjs` 展示调整操作后可触发落石并通关的单条路线；但单条成功不能证明合理操作余量。搜索中一组站位法有效目标区约0.15格，约1.8个满速逻辑tick，不符合“不追求精度”的目标，尚需设计更宽松的解法或机关参数。另一条可绕过落石的路线不当作机关有效性的证据。

这不是可直接用于所有玩家关卡的生产规则；须先完成落石、隐刺、塌地、弹簧及组合的自然/知情路线和宽容度验证，保留v2–v11旧快照，再进行手机试玩。
