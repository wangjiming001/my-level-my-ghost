# 黑色主角试玩（基于 v17 / 规则 v11）

用户提供黑色椭圆头、白眼睛、长四肢角色并要求替换试玩。基于参考图生成12帧透明动作图集，作为assets/hero_black.png；生成的PNG按原样保留，逐帧透明边界仅用于运行时裁切分析，没有重新绘制源图。

动作顺序：待机0–3、跑步4–7、上升8、下落9、眩晕10、失败11。每帧源矩形存放于art3.js的HERO_FRAMES；统一使用同一像素缩放与脚底锚点，保留弯腿/腾空姿势的自然高度变化。左右翻转、起跳拉伸、落地压缩、死亡旋转沿用既有渲染逻辑。影子着色保留眼睛明暗对比。

主角碰撞盒、速度、跳跃、v17五关与机关参数未改。旧hero06图集保留以便恢复；原矢量角色只作为图片加载失败时的备用显示。菜单标记“v17 · 黑色主角试玩”。

构建ES2017检查通过；390×844浏览器五关知情通关，以及五关12tick延迟反应失败对照全部通过，无页面错误。此为浏览器验证，手机实际观感由用户试玩确认。仅生成预览，不送审。
