# 人物与机关比例：初步测量

目标：保留用户确定的黑色主角，测量后建立可复用的地图比例；不可仅按显示图缩放就宣称物理已对齐。

## 已有证据

- 原作 Poki 网页版第一扇门第一小关，录像中的游戏画面约836像素宽，房间约658像素宽，窄坑约31像素宽。静止人物黑色轮廓约10像素宽、25像素高，动作中轮廓会变化；这是可见像素，不是源码碰撞盒。
- 我们的固定地图12列，一格1024物理单位；人物碰撞盒640×800，宽为窄坑的0.625倍，高为窄坑的0.781倍。角色动画绘制范围随动作变化，也不等于碰撞盒。
- 原作第四小关正常录像的画面拟合：人物约157像素/秒，即约5.0个窄坑宽/秒；坑右边缘约233像素/秒，约为人物速度的1.48倍。采样可能掉帧，并非源码速度。
- 本项目人物最大水平速度56单位/tick，60 tick/秒，即约3.28格/秒；追赶坑速度84单位/tick，约为人物的1.5倍。
- 本项目平地短按跳10 tick并持续向右，实测35 tick重新落地，水平位移约1.75格，最高升起约1.50格；起步加速影响这条测量，不能直接当作满速跳距。

## 尚未完成

原作碰撞盒、完整起跳到落地时长/距离、不同小关触发条件还没有足够证据；本次尚未修改引擎、地图或快照版本，也没有完成五关比例校准和复用验证。画面尺寸、人物可见轮廓与碰撞盒是不同测量对象，不能直接得出碰撞盒精确倍数。

下一步需以正常速度操作原作，分别记录地面、人物可见轮廓、坑边、起跳与落地时刻，测多次短按与长按；然后设计保留v2–v11旧快照的版本化参数，在五关测试盲跑、已知路线、反应窗口、重试和评论快照，再验证平移布局可复用。若不能拿到原作内部碰撞盒，只能报告画面推算范围。
