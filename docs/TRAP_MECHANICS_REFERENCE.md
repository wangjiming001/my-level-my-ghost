已查公开介绍与攻略索引；未逐帧分析所有版本全部关卡，也未获得原作代码。下表是主要机制分类，不冒称原作完整参数表。精确触发距离、速度、碰撞顺序未知；本项目参数由自己的双路线测试确定。

## 主要机制分类

| 类型 | 资料支持 | 应提炼的规律 | 我们当前状态 |
| --- | --- | --- | --- |
| 隐刺/位移尖刺 | Poki、Apple | 安全外观突然变化；已知位置后提前跳或诱出 | 隐刺已有，位移未做 |
| 消失地面/塌地 | Poki、Apple | 踩踏或接近改变支撑，迫使提前选起跳点 | 塌地已有，编辑器尚未开放 |
| 下落物/压顶 | Poki | 接近启动，危险快速执行，结束后地形改变 | 落石已有，v6 分离触发边缘与致命列 |
| 移动锯片/墙 | Poki、Apple | 与玩家的跳跃或前进形成时序冲突 | 未实现 |
| 落地后移动的平台 | Poki | 落点不再可靠，需改变下一步 | 未实现 |
| 移动/欺骗出口 | Poki | 接近胜利仍有一次预期反转 | 未实现 |
| 左右输入反转 | Poki、Apple | 路径不变，输入意义变化 | 未实现 |
| 跳跃高度/次数变化 | Poki | 先建立原规则，再改变运动能力 | 未实现 |
| 重力变化 | Apple | 支撑面和运动方向改变 | 未实现 |
| 金币诱饵/用途变化 | Poki、Apple | 奖励外观不保证奖励用途 | 未实现 |
| 传送至危险位置 | Apple | 空间预期被打破，出口也要观察 | 未实现 |
| 追踪弹、侧向落弹 | Poki 后期世界介绍 | 方向和追踪目标改变；不能只增快落石 | 未实现 |
| 飞行能力失效 | Poki 后期世界介绍 | 在依赖某能力时撤销能力 | 未实现 |
| 多分身与异常规则 | Poki 后期世界介绍 | 同一输入影响多个对象，解法依赖联动 | 未实现 |
| 主动触发对手机关 | Poki、Steam 官方商店 | 玩家制造时机，不是随机发难 | 不做实时联机；用评论造关替代 |

这些并不都需要现在开发；按可复用程度分批实现。先把现有隐刺、塌地、落石、弹簧的语法固定，再扩展移动危险物和出口反转。

## 必须统一的四件事

1. 触发区：什么动作、什么位置引发，边界必须可复现。
2. 伤害区：何时、何处致命；可与触发区分离。已知位置有安全试探点，不强求触发后反应躲避。
3. 结束状态：动作结束后是实体、空洞、持续危险还是恢复原状，不能靠动画猜。
4. 复位：每次重试恢复一致状态；不因死亡次数偷偷更改机关。

默认节奏：初见可能被立即击中，重试利用知识提前规避。动作速度不能靠“缓慢等待玩家反应”达成可通关，安全必须来自选位和路径。隐刺、落石、塌地不统一成同一种定时等待题。

## 自动化检查矩阵

| 检查 | 通过条件 |
| --- | --- |
| 盲冲路线 | 在预期位置中招，不是机关慢到从身后落下 |
| 知情路线 | 在触发边缘停下/退回/提前跳，动作完成后稳定通过 |
| 地形复用 | 换外观不改变物理；新组合无需重写专用触发代码 |
| 高速碰撞 | 移动路径和落地帧都有伤害判定，不能穿透玩家 |
| 结果一致 | 同版本、同地图、同输入得到同一状态序列 |
| 快速重试 | 短暂夸张翻车后自动重生，不强制慢回放 |
| 全图可读 | 不靠移动镜头掩盖机关，角色和机关视觉位置不误导碰撞 |
| 评论独立恢复 | 关卡＋操作回放完整封装在 ≤2048 字节 UTF-8 快照中 |

测试只能证明定义的条件，不能证明“必然好笑”。人工体验仍保留，但安排为一批机关的整体验收，不把每个触发距离都交给用户猜。

## v8 速度复测

根据原作正常录像测得第四关坑边/人物速度比约1.48；v7只有0.429，不能体现追赶。v8按1.5倍和短暂停顿后恢复跑的对照标定。原作第三关仍向左，本项目v8按反馈改为起跳后向右追落点，属于原创变化。数据和验收范围见 PACING_MEASUREMENTS.md。
